# Roadmap

## v0.3.0 Model Quality

- Full uncapped training on stronger hardware.
- `A`, `L`, and `R` recovery.
- Beat segmentation and R-peak alignment validation.
- Per-class threshold calibration.
- Minority-class methods that preserve ECG morphology.
- Repeated grouped-record validation.

## v0.4.0 MLOps

- MLflow or Weights & Biases experiment tracking.
- Versioned model registry.
- Artifact hash validation and rollback docs.
- Automated evaluation report generation.
- CI benchmark summaries for lightweight smoke runs.

## v0.5.0 Deployment

- Hosted API after verified health checks.
- Hosted Streamlit or web demo UI.
- Downloadable sample non-clinical artifacts.
- Public deployment docs with only verified URLs.
- Production-style secrets and environment documentation.

## v1.0.0 Research-Grade

- External validation dataset.
- Comparative benchmarks against stronger baselines.
- Better arrhythmia performance with stable minority-class recall.
- Calibration and uncertainty analysis.
- Independent ECG/domain review.
- Expanded model card and risk documentation.
